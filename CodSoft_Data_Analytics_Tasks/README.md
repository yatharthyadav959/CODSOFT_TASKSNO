# CodSoft Data Analytics Internship — Tasks 1–3

This starter project uses a **synthetic practice sales dataset**. Replace it with a permitted dataset if your internship instructions require a real/public dataset. Do not describe synthetic data as real business data.

## Requirements
Python 3.10+ recommended.

```bash
python -m pip install pandas matplotlib seaborn
```

## Run tasks in order
Run these commands from this folder:

```bash
python task1_data_cleaning/clean_data.py
python task2_eda/eda.py
python task3_visualization/dashboard.py
```

## What each task delivers
- **Task 1:** Inspects structure, reports missing values and duplicates, standardizes text, converts data types, handles invalid/missing values, exports `data/sales_cleaned.csv`.
- **Task 2:** Descriptive statistics, product/region/payment comparisons, monthly sales, correlations, and IQR-based outlier screening.
- **Task 3:** Saves five charts under `output/charts/`.
